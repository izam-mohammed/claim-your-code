## In short

`claim` is a Go command-line tool that finds `Co-Authored-By: Claude ...
<...@anthropic.com>` trailers in git history and rewrites them away, in a
local repository or in remote GitHub repositories, pull requests,
organisations and users. Every scan is recorded as an encrypted report that
`claim revert` can undo. It ships as one static binary through GitHub
Releases, a Homebrew tap, a Scoop bucket, `install.sh` and `go install`.

## What a person can use

### Cleaning history

- Scan and clean a local repository with `claim <folder>`, with
  `--dry-run` and `--force` (`cmd/claim/local.go`, `internal/scanner/`,
  `internal/rewriter/`; PR `#10`).
- Pick which branches to scan and rewrite, with progress
  (`internal/scanner/scanner.go`; commit `9dbfeec`).
- Only Claude co-author lines are matched; other co-authors stay
  (`internal/pattern/pattern.go`; README "What it matches").

### Remote repositories

- Scan a GitHub repository, pull request, organisation or user by URL or
  subcommand (`claim repo`, `claim pr`, `claim org`, `claim user`),
  scan-only by default, `--apply` to rewrite and force-push
  (`cmd/claim/remote.go`, `internal/remote/parse.go`,
  `internal/github/`; PR `#10`).
- Multi-repo scans through the API (`--api-only`) or by cloning
  (`internal/github/client.go`, `internal/github/clone.go`).
- Public repositories read without a token (commit `f9712ac`).

### Accounts and reports

- Sign in by GitHub OAuth device flow, the `gh` session, a pasted token,
  `CLAIM_GITHUB_TOKEN` or `GITHUB_TOKEN`; accounts saved encrypted with
  AES-256-GCM under a machine-derived key (`internal/auth/`,
  `internal/crypt/crypt.go`; commits `4c4ead3`, `d80ceeb`).
- `claim logout` removes a saved account (`cmd/claim/main.go`).
- `claim report` lists or shows reports, `claim revert <id>` restores the
  branch tips a clean rewrote (`cmd/claim/reports.go`,
  `internal/report/`).
- Every command and flag has its own help page (`cmd/claim/help.go`;
  PR `#9`).

### Install

- GitHub Release `v0.1.0` (05/09/2026) with archives for linux, darwin and
  windows on amd64 and arm64, plus the Homebrew formula and Scoop manifest
  goreleaser pushes (`.goreleaser.yml`, `.github/workflows/release.yml`,
  commit `a5ba6db`).
- `install.sh` downloads the matching release archive (`install.sh`).

## Under the hood

- **Shape**: one binary, `cmd/claim/` (commands, prompts, output) over
  `internal/` packages: `auth`, `crypt`, `discover`, `filter`, `github`,
  `pattern`, `remote`, `report`, `rewriter`, `scanner`.
- **Data**: reports and saved accounts as encrypted files in the user's
  config directory (`internal/report/report.go`, `internal/auth/cache.go`).
- **Integrations**: GitHub REST API and OAuth device flow
  (`internal/github/client.go`, `internal/auth/oauth.go`); go-git for
  scanning; `git filter-branch` for the rewrite (README "How it works").
- **Standards and CI**: no single check command; the Makefile has `test`
  (`go test ./...`) and `lint` (`go vet ./...`). `.github/workflows/ci.yml`
  runs test, vet and build on ubuntu, macos and windows, on
  `workflow_dispatch` only (commit `34b4750`).
  `.github/workflows/security.yml` calls the shared gate
  `izam-mohammed/.github/.github/workflows/security-scan.yml` pinned to
  `ff76c48` with `ecosystem: go` on every PR and weekly.
  `.pre-commit-config.yaml` runs gitleaks and the pre-commit hygiene hooks.
  Dependabot covers gomod and github-actions (`.github/dependabot.yml`).
  Recorded in `docs/standards.md`, written with this snapshot.
